# AKG 算子任务

仅用于 AKG 算子工程；普通业务代码、通用性能分析或文档问题不启动本流程。已提供的目标、参数和配置状态可直接复用，只补问会阻塞执行的信息。

- 首次接入、仓库或环境异常：读 [仓库和执行契约](references/kernelgen.md) 的环境部分。
- 提取任务与后端生成：读同一参考的任务和命令部分。

保留实际工具契约：`akg_cli` 已废弃；使用 `run_workflow.py --workflow kernelgen`。该工作流以前台受控执行并跟踪结果，失败如实报告，不擅自以其他生成器冒充成功。

不重配已验证可用的 `~/.akg/settings.json`；缺失的模型、端点和密钥由用户在本机配置。任务授权不允许覆盖现有仓库改动、切换不明分支或改变外部账户。

交付生成物路径、所用 framework/backend/dsl/arch、相关验证结果和未完成项。环境检查通过或进程启动不等于算子生成及设备验证完成。
