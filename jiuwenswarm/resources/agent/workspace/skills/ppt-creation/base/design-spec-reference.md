# 设计记录参考

design-spec.md 记录对执行有帮助的决定。字段按任务规模选取，不要求固定章节、字数或 Hero 页配额；机器必填项由 execution-lock/evidence-plan schema 负责。

- 项目：受众、用途、语言、页数/时长、用户指定结构、材料范围。
- 模板：来源、画布、合并模式、固定外围元素、保留要求。
- 叙事：核心信息与实际来源，章节/页面顺序。
- 跨页系统：字体角色与可读性、颜色语义、图片比例/裁切、可编辑图表策略。
- 页面：role、title、core_message、真实内容块、summary、visual strategy、资产 ID、composition 和必要来源说明。
- 参考：采用的 layout id/path 或不适用原因；只看本页需要的参考，不复制整库。
- QA：易拥挤/截断/事实不确定的页面，以及真正需要检查的结构/来源边界。

内容数量以能清楚表达用户要求为准，不按每页 400–700 字补料。Hero 标签可用于标记值得重点复核的页面，可为零。引用方式遵守素材使用权及当前审计器：使用论文原图的页面需 addSourceNote，不能仅存 evidence-plan 后声称该检查通过。

当设计改变时同步 machine contracts，保持实际页面、素材状态和来源一致。
