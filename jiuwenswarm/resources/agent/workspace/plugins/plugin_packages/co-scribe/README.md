## 你安装的是什么

**十个云文档工具（原生装配，随本插件启用）**：

| 工具 | 作用 |
|---|---|
| `clouddoc_read` | 读取文档全文与修订号（表格/幻灯片附区域坐标） |
| `clouddoc_list_documents` | 列出本连接纳管的文档 |
| `clouddoc_list_comments` | 列批注（含指派与 @ 标记） |
| `clouddoc_reply_comment` | 在批注线程回帖 |
| `clouddoc_batch_edit` | 原子批量文本编辑（聊天路径唯一写入原语） |
| `clouddoc_write_region` | 区域声明式写入（移动/清空/重排） |
| `clouddoc_apply_for_comment` | 无人值守路径按批注施工（聊天中拒绝） |
| `clouddoc_create_document` | 建档并共享（授权类，永远需确认） |
| `clouddoc_workmode_get / edit` | 读/改写作约定（回执可回退） |

**Mandate 委托机制（焊在工具内，委托档生效）**：

| 机制 | 作用 |
|---|---|
| 回执台账 | 每笔写入记录改前/改后内容，执行者署名 |
| 一键机械回退 | 锚判据不符整批拒绝，绝不近似恢复 |
| 范围轨 / 谓词轨 | 批注引文锚定；"剪短/清空/删掉X"写前机械校验 |
| 权限底线 | 不可逆写与授权类动作永远需确认（代码减法，任何模式不可豁免） |
| 先读后写 | 未读过的文档拒绝写入 |
| watch 常设授权 | 关/建议权/操作权三档，默认 30 天期限，granted−used 使用审计 |
| 无人值守 | 批注 @指派自动派发，全程留痕 |

**界面**：

| 位置 | 管什么 |
|---|---|
| 设置 → Cloud Docs | 接入：服务账号密钥、连接管理 |
| 文档 面板 | 保障开关（委托/直连）、watch 授权、回执与回退、使用审计 |

**平台已知边界**（实测于真实租户，属平台契约而非本插件限制）：

| 平台 | 边界 | 应对 |
|---|---|---|
| 飞书 | 批注引文在**服务端截断于 128 字符**且无标记（选区高亮完整，API 只存前 128 字） | 超过 128 字符的选区无法作为无人值守的授权边界，会被明确拒绝并提示；大范围修改请在 Jiuwen 聊天中进行 |
| 飞书 | 批注无「指派」概念 | @ 即触发无人值守（修改被禁闭在本文档内） |
| Google | 批注引文约 419 字符截断，带「…」标记 | 截断可检测，同样拒绝并提示 |

卸载只收起能力：连接配置、授权登记与回执历史保留在本机，重新安装即恢复。
